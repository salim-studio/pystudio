# PyStudio Brand Guidelines

> Official visual identity for PyStudio. All public copy is in English.
> Copyright © 2026 salim-slimani. All rights reserved.

## 1. Logo

- **Main logo:** `public/logo.svg`
- **Favicon:** `public/favicon.svg`
- **Banner:** `public/pystudio-banner.svg`

Rules:

- Do not stretch, recolor, or add shadows to the logo.
- Keep clear space equal to the height of the terminal `>` mark on all sides.
- Minimum display size: 24px for the icon, 120px for the full lockup.
- Prefer the SVG on light and dark backgrounds; the emerald mark is designed for both.

## 2. Colors

| Token | Hex | Usage |
|---|---|---|
| Primary emerald | `#10B981` | Actions, run buttons, links, badges |
| Deep emerald | `#059669` | Hover states, gradients |
| Teal accent | `#0D9488` | Charts, secondary highlights |
| Ink | `#09090B` | Headings, banner background |
| Neutral grays | Zinc scale | UI surfaces and borders |
| AI purple | `#7C3AED` | AI Tutor only |

Gradient (logo and banner): `#10B981 → #059669 → #0D9488`.

## 3. Typography

- **UI:** Inter, Segoe UI, system sans. Bold headings, medium labels, tight tracking for the wordmark.
- **Code:** JetBrains Mono, Consolas, monospace.
- Write in plain, direct English. Avoid jargon in beginner mode.

## 4. Imagery

- Use the dark banner with grid + code card for social preview and docs headers.
- Screenshots should use dark theme by default for consistency.
- Charts: emerald/teal palette, white background in light mode, zinc-950 in dark mode.

## 5. Voice

- Clear, encouraging, practical.
- Example: "Run a cell to see real-time output." Not: "Execute computational unit to materialize results."
- Beginner mode explains; Pro mode stays concise.
